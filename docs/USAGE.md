# 詳しい使い方

概要は [README](../README.md) を参照。

## 操作

1. **動画を追加**：サイドバー上の「＋」（⌘O、何本でもまとめて選べる）、ウインドウか Dock のアイコンへドロップ、ファイル ▸ 最近使った項目を開く、または Finder の「このアプリケーションで開く」（複数可）。動画がないときは、3 つの手順（追加 → 何を隠すか選ぶ → 確かめて書き出す）と「動画を追加…」ボタン、「処理はすべてこのMacの中で行います」の表示が出る。写真（JPEG・HEIC・PNG など）を入れたときは動画として扱わず、顔写真は設定（⌘,）から登録するよう案内する。追加すると「何を隠しますか？」と聞かれる。「画面の文字」「人の顔」「両方」から選ぶと、まとめて追加した動画すべてに使い、選んだものだけを探し始める（前回と同じものに「前回と同じ ⏎」と出て、Return キーで選べる。「キャンセル」（esc）で動画を追加せずに閉じる。選ぶまで右の欄には「隠すものを選んでください」とだけ出る）。顔は追加した順に 1 本ずつ探す（表示中の動画を優先）。「画面の文字」だけを選んだ動画は顔を探さず、右の一覧も「画面の文字」で開く。あとから「人の顔」の「顔を探す」で顔も探せる。「両方」では顔と文字を同時に探す。一覧の状態は「順番待ち／顔を探しています n%／文字を読み取っています n%／n人中m人・文字 n行を隠す／書き出し済み／開けません」
2. **隠す人**（右の一覧）：顔を押すと（チェックボックスでも、動画の中の顔でも）その人の顔を隠し、もう一度押すと外れる。名前のあたりを押すと、その人が映る場面を表示する。行の右の ⏭ で、その人が映る次の場面へ進む。一覧で人を選んで Return キーを押しても、隠す／外すが切り替わる
   - 選んだ人の行の「隠し方」メニュー：「基本の隠し方（モザイク／ぼかし）」か、スタンプ（顔に重ねる画像）を選ぶ。「画像を選んでスタンプにする…」で PNG・JPEG・HEIC などを選ぶと、その人の顔に重ね、スタンプの一覧に加わる。顔の写真なら写真の顔を動画の顔に合わせ、写真が大きければ顔のまわりだけを使う。同じ人かもしれない人にも同じスタンプが付く。顔を隠しきれる画像なら、検出できた場面ではスタンプの下にモザイクをかけないので、髪型や頭の輪郭はスタンプの周りから見える。顔を見失って位置を推し量っている場面（前後も続ける時間など）と、透明や半透明の部分から顔が透ける・いまの大きさでは顔がはみ出す画像では、スタンプの下にもモザイク（ぼかし）をかける（後者は行と書き出しのシートに、スタンプだけで隠す直し方が出る）。いらなくなったスタンプは、同じメニューの「保存したスタンプを削除」から消せる（確認が出る。使っていた人は基本の隠し方に戻る。設定の「スタンプ」からも消せる）
   - 「全員（m／n人）」で全員をまとめて切り替える（一部だけのときは「−」）。「人物」メニューの「全員を隠す」（⇧⌘A）・「全員を隠すのをやめる」も同じ。通行人が多い動画は、全員を選んでから残したい人だけ外すと早い
   - 「人物Nと同じ人かもしれません」：同じ人が分かれて出た可能性。選ぶと一緒に選ばれる
   - 「登録した顔に似ています」「『動画名』で選んだ人に似ています」：最初から選ばれている／選んでいない似た人。選んでいない似た人がいると一覧の上に件数と「まとめて選ぶ」が出る（自動では選ばない）
   - 間違えたら ⌘Z で取り消せる（⇧⌘Z でやり直し）
3. **動画と再生バー**：「隠した表示」では、書き出しと同じモザイクのまま再生できる。再生バーは常に表示され、コマ送りと、選んだ人が映る区間の太線（隠す人はアクセント色）が出る。つまみを動かすと、絵は追いつける速さで更新され、離した位置のコマで止まる。つまみの上にポインタを置くとその位置の時刻が出る。書き出した後は「確かめてほしい場面」がつまみの上に ▼ で出て、押すと書き出し結果のその場面へ移る。キー操作は QuickTime Player と同じく、スペースで再生／一時停止、← → で 1 コマ、⇧← ⇧→ で 1 秒、K で一時停止、L で再生（もう一度押すと速くなる）。文字の入力中は効かない。速さ（0.5 倍〜2 倍）は「再生」メニューの「速さ」でも変えられ、ふつう以外の間は時刻の横に表示する（動画を切り替えるとふつうに戻る）。「再生」メニューには前の／次の「確かめてほしい場面」もある。一時停止中は顔に枠が出る（アクセント色の実線＝隠す人、白の点線＝隠さない人）。「画面の文字」では、一時停止中に隠す範囲がオレンジの点線で出る。顔の枠と文字の枠は、再生バー右端の枠ボタン（表示中は青く塗られる）か ⌘B でまとめて隠せる。隠す人の枠は、モザイクやぼかしがかかる範囲（「隠す広さ」で広げた範囲）で出る。表示は「元の動画／隠した表示／書き出し結果」（⌘1〜⌘3。「表示」メニューでは今の表示にチェックが付く）。左の動画の一覧は「表示」メニューの「動画の一覧を隠す」（⌃⌘S）、右の欄は「隠すものの欄を閉じる」（⌃⌘I）でも開閉できる。小さな顔や画面の文字を確かめるときは拡大できる（最大 8 倍）：「表示」メニューの「拡大」（⌘+）「縮小」（⌘−）「全体を表示」（⌘0。ポインタが動画の上にあれば、その位置を中心に拡大する）、または動画の上でピンチ（トラックパッドの 2 本指のダブルタップで 2 倍と全体を切り替え）。拡大中は動画をドラッグするかスクロールして見る場所を動かす。拡大中は動画の左下に、動画全体の縮小表示と見えている範囲の白枠、拡大率が出る（押すと全体に戻る）。拡大率は 3 つの表示を切り替えても変わらず、動画を切り替えたとき、「確かめてほしい場面」や「再生して確かめる」を押したときは全体に戻る（書き出した動画は全体で確かめるため）。拡大中に一覧から人を選ぶと、その人の顔を真ん中に出す。顔か文字を探した後は、時刻の横に表示中のコマの番号が出る（番号が変わると枠も変わる。全体のコマ数はポインタを重ねると出る）。ウインドウが狭いときは、コマの番号、時刻の順に省く
4. **隠し方の調整**（一覧の下、開閉できる。すべての動画に共通）：基本の隠し方（モザイク／ぼかし。顔と画面の文字の両方に使う）、モザイクの粗さ・ぼかしの強さ（既定はおまかせ＝長辺÷60。「おまかせ」を外すと 8〜96px で指定。ぼかしも同じ大きさでモザイクにしてからぼかすので、モザイクより読み取りやすくはならない）、スタンプの大きさ（スタンプを使う人がいるときだけ。既定 120%、80〜200%）、顔の前後も続ける時間（既定 1 秒、0〜3 秒）、モザイク（ぼかし）の広さ（45%）。動かすとすぐ「隠した表示」へ反映される。「画面の文字」の一覧にも「隠し方（すべての動画に共通）」として同じ基本の隠し方と粗さ・強さが出る
5. **書き出す**：ツールバーの「書き出す…」か ⌘E。本数にかかわらず同じシートが開き、書き出す動画（まだ書き出していない動画にチェック。2 本以上なら「すべて」で一括）と保存先（元の動画と同じフォルダ／ほかのフォルダ）を確かめてから書き出す。名前は「元の名前_mosaic」で、同じ名前があれば上書きせず番号を付ける。顔や文字をまだ探している動画は、終わるまで書き出せない（「両方」を選んだ動画で、片方だけが入った動画にならないように）。シートの上には「自動で見つからなかった顔や文字は隠れません。公開する前に、書き出した動画を最後まで確かめてください。」と出る。動画ごとに、顔が見つかったのに誰も選んでいない（「顔がN人見つかりましたが、誰も選んでいません（顔は隠れません）」）、「自動で隠すもの」で外した種類がある、探すのを中止した・失敗した、スタンプの画像から顔が透ける・はみ出す（そのときはスタンプの下にもモザイクをかけて書き出す）のような注意が出る。顔か文字の片方だけを選んだ動画は、もう片方について「人の顔は探していません（顔が映っていても隠れません）」のような注意を出す。「隠す言葉」に、どの動画でも見つかっていない言葉があるときも注意が出る。選んでいない似た人がいる動画には注意と「確かめる」（シートを閉じてその動画へ移る）が出る。1 本でも複数でも、進み具合のバーと「中止」はサイドバーの下に出る（右の欄を閉じていても見える）。動画の行と右の欄には「書き出し中 n%」の文字だけが出る（右の欄にも「中止」がある）。複数は 1 本ずつ順に書き出す。中止すると途中のファイルは消す
6. **結果**：一覧の上に「書き出しました」とファイル名、「再生して確かめる」「Finderで表示」、前後より隠す顔の数が減る「確かめてほしい場面」が出る。書き出した後に人の選択や隠し方（スタンプ・時間・広さ・粗さ・ぼかし・スタンプの大きさ）を変えると「書き出し済み」が外れ、もう一度書き出すよう表示される
7. **画面の文字**（右の一覧の上で「画面の文字」に切り替える）：iPhone などの画面録画や、画面をカメラで撮った動画に映る文字を隠す。「画面の文字」か「両方」を選んだ動画は、追加すると読み取りを始める（画面が止まっている間は読み取りを省くので、動きの多い動画ほど時間がかかる）。「人の顔」だけを選んだ動画は読み取らず、「画面の文字」に切り替えたときの「この動画の画面の文字を読み取る」で読み取る。設定を変えて隠す範囲を作り直している間は「隠す範囲を作り直しています…」と出る。顔のモザイクと一緒に使え、書き出しには両方が入る
   - **この動画だけ** ▸ **読み取れた文字をすべて隠す**：スマホやパソコンの画面をカメラで撮った動画向け。読み取れた行をすべて隠す。読み取れない瞬間（ブレ・反射・指）も、同じ場所に文字がまた読めれば 6 秒まではモザイクを続ける。動画に入れた字幕や服・看板の文字も隠れる
   - **自動で隠すもの**（すべての動画に共通）：電話番号・カード番号などの数字（6桁以上。A-123456 のような英字付きも）、メールアドレス、URL、住所・郵便番号、人の名前（よくある名字に、名前（漢字・カタカナ・ひらがな）や「さん・様・くん・ちゃん・氏・先生」「です」が続く形と、名字だけの行。一覧にない名字は、漢字 2〜6 文字（とその後の名前）に「さん・様・くん・ちゃん・先生・氏」や決まった肩書き・呼び方（部長・課長・社長・先輩・監督・ママなど）が続く形。森・林など 1 文字の名字は、「さん」や肩書き・空白が続くときか、行が名前だけ（「林健一」）のとき。名前を残さないよう、社名や「患者さん」「山田太郎部長」の「部」、「金曜日」だけの行のような言葉も隠れることがある）。種類ごとに、この動画で見つかった行数が右に出る。説明の続きは、項目にポインタを重ねると出る。外した種類はほかの動画でも隠さない。見つかった部分だけを隠し、行のほかの文字は残す。住所は見つかった所から行の終わりまでと、すぐ下に続く行（建物名・部屋番号）も隠す。途中で折り返したメールアドレス・URL・電話番号などの数字（「sato.ichi」／「ro@example.jp」、「example」／「.com/yamada」、「080-0000-」／「2222」、「090 12」／「34 5678」など）は、上の行の終わりと下の行の始めの英数字・記号を隠す
   - **隠す言葉**（すべての動画に共通）：「＋ 言葉を追加」で欄を増やして、名前やアカウント名などを入れる（Return で確定すると次の空欄が出るので、続けて入れられる。Return を押さずにほかの欄やタブへ移ったとき、書き出すときも確定する。入れた言葉はその場で書き直せ、⊗ か、空にして Return で消える。空にしただけで欄を離れたときは、元の言葉のまま残す）。画面のどこに出てもその言葉の部分を隠す。空白の有無、大文字・小文字、全角・半角は区別しない。言葉のすぐ後に漢字かカタカナが続くとき（「鈴木 次郎」の「次郎」）は、4 文字までそれも隠す。入れた言葉の下に「この動画でN行」と出る（ほかの動画でだけ見つかったときは「この動画にはありません（ほかの動画でN行）」）。どの動画でも見つからないときはオレンジで「…見つかりませんでした。…」と出るので、字の違い（高／髙など）や読み違いがないか、下の一覧で確かめる
   - **見つかった文字**：上に、読み取れなかった文字は隠せないという注意が出る。チェックを入れた行は行全体を隠す（⌘Z で取り消せる）。チェックがなくても、自動で見つかった部分は隠れる。各行の下に「行全体を隠しています」「一部を隠しています（数字・名前など）」「隠していません」と、最初に映る時刻が出る。「行全体は隠していない行だけを表示（N行）」をオンにすると、何も隠していない行と一部だけ隠した行が並ぶので、隠し忘れ（一部だけの行は、残った文字に名前などがないか）を探しやすい。動画を切り替えるとオフに戻る。文字を押すとその行が映る場面へ移る。一瞬だけ読み取れた文字は下にまとめて折りたたむ
   - スクロールして文字が動いても、モザイクは追いかける。通知などで一時的に隠れて読めなかった行も、同じ場所に似た文字がまた読めれば 3 秒まではモザイクを続け、読み違えた行（「090」を「O90」など）も、前後の正しく読めた行と同じ部分を隠す。読み取れなかった文字は隠せないので、書き出した動画を必ず確かめる
8. **一覧から取り除く**：右クリック ▸ 一覧から取り除く（⌘⌫）。人を選んだまま書き出していない動画は確認が出る。元のファイルは消さない
9. **終了**：書き出していない動画があるとき・書き出し中は確認が出る（書き出し中に終了すると、中止して途中のファイルを消してから終わる）

## 設定（⌘,）


- **検出**：顔を探す精度（高精度＝画面を 4×4 に分けても探す／標準＝3×3／速度優先＝2×2）。変えたら「人物」メニューの「顔を探し直す」か一覧の「探し直す」で反映
- **登録した顔**：どの動画でも隠す人の顔写真。似ている人が最初から選ばれる。判定は確実ではないので、必ず一覧で確かめる
- **スタンプ**：これまでに選んだスタンプの画像。「削除」（または右クリック）を押し、確認で「削除」を選ぶと消える。使っていた人は基本の隠し方に戻る（取り消せない）
- 「画面の文字」の「自動で隠すもの」と「隠す言葉」も、次回まで残る

設定はこの Mac の中に保存され、次回も使われる。
