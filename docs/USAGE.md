# 詳しい使い方

概要は [README](../README.md) を参照。

## 操作

1. **動画を追加**：サイドバー上の「＋」（⌘O、何本でもまとめて選べる）、ウインドウか Dock のアイコンへドロップ、ファイル ▸ 最近使った項目を開く、または Finder の「このアプリケーションで開く」（複数可）。動画がないときは、3 つの手順（追加 → 人を選ぶ → 書き出す）と「動画を追加…」ボタン、「処理はすべてこのMacの中で行います」の表示が出る。写真（JPEG・HEIC・PNG など）を入れたときは動画として扱わず、顔写真は設定（⌘,）から登録するよう案内する。追加すると「何を隠しますか？」と聞かれる。「人の顔」「画面の文字」「両方」から選ぶと、まとめて追加した動画すべてに使い、選んだものだけを探し始める（Return キーで前回と同じものを選ぶ。「追加しない」で取りやめ）。顔は追加した順に 1 本ずつ探す（表示中の動画を優先）。「画面の文字」だけを選んだ動画は顔を探さず、右の一覧も「画面の文字」で開く。あとから「人の顔」の「顔を探す」で顔も探せる。「両方」では顔と文字を同時に探す。一覧の状態は「順番待ち／顔を探しています n%／画面の文字を読み取っています n%／n人中m人・文字 n行にモザイク／書き出し済み／開けません」
2. **モザイクをかける人**（右の一覧）：顔を押すと（チェックボックスでも、動画の中の顔でも）その人にモザイクがかかり、もう一度押すと外れる。名前のあたりを押すと、その人が映る場面を表示する。行の右の ⏭ で、その人が映る次の場面へ進む
   - 「全員（m／n人）」で全員をまとめて切り替える（一部だけのときは「−」）。「人物」メニューの「全員にモザイクをかける」（⇧⌘A）・「全員のモザイクを外す」も同じ。通行人が多い動画は、全員を選んでから残したい人だけ外すと早い
   - 「人物Nと同じ人かもしれません」：同じ人が分かれて出た可能性。選ぶと一緒に選ばれる
   - 「登録した顔に似ています」「『動画名』で選んだ人に似ています」：最初から選ばれている／選んでいない似た人。選んでいない似た人がいると一覧の上に件数と「まとめて選ぶ」が出る（自動では選ばない）
   - 間違えたら ⌘Z で取り消せる（⇧⌘Z でやり直し）
3. **動画と再生バー**：「モザイクあり」表示では、書き出しと同じモザイクのまま再生できる。再生バーは常に表示され、コマ送りと、選んだ人が映る区間の線（モザイクありはアクセント色）が出る。一時停止中は顔に枠が出る（アクセント色の実線＝モザイクあり、白の点線＝なし）。枠は右上のボタンか ⌘B で隠せる。表示は「モザイクなし／モザイクあり／書き出し結果」（⌘1〜⌘3）
4. **モザイクの調整**（一覧の下、開閉できる。すべての動画に共通）：顔の前後も続ける時間（既定 1 秒、0〜3 秒）、モザイクの広さ（45%）、モザイクの粗さ（既定はおまかせ＝長辺÷60。「おまかせ」を外すと 8〜96px で指定）。動かすとすぐ「モザイクあり」の表示へ反映される
5. **書き出す**：ツールバーの「書き出す…」か ⌘E。本数にかかわらず同じシートが開き、書き出す動画（まだ書き出していない動画にチェック、「すべて」で一括）と保存先（元の動画と同じフォルダ／ほかのフォルダ）を確かめてから書き出す。名前は「元の名前_mosaic」で、同じ名前があれば上書きせず番号を付ける。顔や文字をまだ探している動画は、終わるまで書き出せない（「両方」を選んだ動画で、片方だけが入った動画にならないように）。探すのを中止した・失敗した方は、「顔は探していないので、モザイクがかかりません」のような注意が出る。選んでいない似た人がいる動画には注意と「確かめる」（シートを閉じてその動画へ移る）が出る。複数は 1 本ずつ順に書き出し、進捗はサイドバーと一覧に出る。中止すると途中のファイルは消す
6. **結果**：一覧の上に「書き出しました」とファイル名、「再生して確かめる」「Finderで表示」、前後よりモザイクの数が減る「確かめてほしい場面」が出る。書き出した後に人の選択やモザイクの調整（時間・広さ・粗さ）を変えると「書き出し済み」が外れ、もう一度書き出すよう表示される
7. **画面の文字**（右の一覧の上で「画面の文字」に切り替える）：iPhone などの画面録画や、画面をカメラで撮った動画に映る文字を隠す。切り替えると画面の文字を読み取る（画面が止まっている間は読み取りを省くので、動きの多い動画ほど時間がかかる）。顔のモザイクと一緒に使え、書き出しには両方が入る
   - **読み取れた文字をすべて隠す**（動画ごと）：スマホやパソコンの画面をカメラで撮った動画向け。読み取れた行をすべて隠す。読み取れない瞬間（ブレ・反射・指）も、同じ場所に文字がまた読めれば 6 秒まではモザイクを続ける。動画に入れた字幕や服・看板の文字も隠れる
   - **自動で隠すもの**（すべての動画に共通）：電話番号・カード番号などの数字（6桁以上。A-123456 のような英字付きも）、メールアドレス、URL、住所・郵便番号、人の名前（よくある名字に、名前（漢字・カタカナ・ひらがな）や「さん・様・くん・ちゃん・氏・先生」「です」が続く形と、名字だけの行。一覧にない名字は、漢字 2〜4 文字（とその後の名前）に「さん・くん・ちゃん・様」が続く形。名前を残さないよう、社名や「患者さん」「山田太郎部長」の「部」のような言葉も隠れることがある）。見つかった部分だけを隠し、行のほかの文字は残す。住所は見つかった所から行の終わりまでと、すぐ下に続く行（建物名・部屋番号）も隠す。途中で折り返したメールアドレス・URL・電話番号などの数字（「sato.ichi」／「ro@example.jp」、「example」／「.com/yamada」、「080-0000-」／「2222」、「090 12」／「34 5678」など）は、上の行の終わりと下の行の始めの英数字・記号を隠す
   - **隠す言葉**（すべての動画に共通）：「＋ 言葉を追加」で欄を増やして、名前やアカウント名などを入れる（Return で確定すると次の空欄が出るので、続けて入れられる。Return を押さずにほかの欄やタブへ移ったとき、書き出すときも確定する。入れた言葉はその場で書き直せ、⊗ か、空にして Return で消える。空にしただけで欄を離れたときは、元の言葉のまま残す）。画面のどこに出てもその言葉の部分を隠す。空白の有無、大文字・小文字、全角・半角は区別しない。言葉のすぐ後に漢字かカタカナが続くとき（「鈴木 次郎」の「次郎」）は、4 文字までそれも隠す
   - **見つかった文字**：チェックを入れた行は行全体を隠す（⌘Z で取り消せる）。文字を押すとその行が映る場面へ移る。一瞬だけ読み取れた文字は下にまとめて折りたたむ
   - スクロールして文字が動いても、モザイクは追いかける。通知などで一時的に隠れて読めなかった行も、同じ場所に似た文字がまた読めれば 3 秒まではモザイクを続け、読み違えた行（「090」を「O90」など）も、前後の正しく読めた行と同じ部分を隠す。読み取れなかった文字は隠せないので、書き出した動画を必ず確かめる
8. **一覧から取り除く**：右クリック ▸ 一覧から取り除く（⌘⌫）。人を選んだまま書き出していない動画は確認が出る。元のファイルは消さない
9. **終了**：書き出していない動画があるとき・書き出し中は確認が出る（書き出し中に終了すると、中止して途中のファイルを消してから終わる）

## 設定（⌘,）


- **検出**：顔を探す精度（高精度＝画面を 4×4 に分けても探す／標準＝3×3／速度優先＝2×2）。変えたら「人物」メニューの「顔を探し直す」か一覧の「探し直す」で反映
- **登録した顔**：どの動画でもモザイクをかける人の顔写真。似ている人が最初から選ばれる。判定は確実ではないので、必ず一覧で確かめる
- 「画面の文字」の「自動で隠すもの」と「隠す言葉」も、次回まで残る

設定はこの Mac の中に保存され、次回も使われる。
