# 隠せるもの・隠せないもの

モザイぷーんは、顔や文字を自動で探します。ただし、探せないものもあります。**公開する前に、書き出した動画を必ず最後まで見て確かめてください。**

概要は [README](../README.md)、操作の詳細は [詳しい使い方](USAGE.md) を参照してください。

## 人の顔

- 隠せるのは**顔だけ**です。後ろ姿や服などは隠せません（文字は「画面の文字」で隠します）
- 次の顔は見落とすことがあります：最初から横顔のまま登場した顔、マスクをした顔、とても小さい顔
- 同じ人が 2 人に分かれて一覧に出ることがあります。一覧の顔はすべて確かめてください
- 登録した顔写真との照合は目安です。最初からチェックが入った人も、入っていない人も確かめてください
- スタンプ（顔に重ねる画像）は顔を覆うだけです。髪型・頭の輪郭・耳・体はスタンプの周りから見えます。顔を検出できた場面では、スタンプの下にモザイクをかけないため、画像の透明・半透明の部分からは顔が見えます（その画像には注意が出ます）
- ぼかしは、同じ大きさのモザイクにしてからぼかします。「強さ」を弱くすると、顔の形や文字が分かることがあります

## 人の名前（画面の文字）

自動で見つけるのは、次の形です。

- よくある名字に、名前や「さん」などが続く形
- 一覧にない名字でも、漢字 2〜6 文字（とその後の名前）に「さん・様・くん・ちゃん・先生・氏」や、決まった肩書き・呼び方（部長・課長・社長・先輩・監督・ママなど）が続く形
- 森・林・原など 1 文字の名字は、「さん」や肩書き・空白が続くときか、行が名前だけ（「林健一」）のとき

次のものは見つからないので、**隠したい名前は「隠す言葉」に入れてください**。

- 珍しい名字、ニックネーム、名前だけの呼びかけ
- カタカナやローマ字だけで書いた名前（「ヤマダ タロウ」「TARO YAMADA」）、半角カタカナの名前
- 2 行にまたがる名前
- 名字だけの呼び捨て（「山田が言った」）
- 名字の後に数字や英字が続く形（「山田 10:32」）
- 文の途中の、1 文字の名字と名前（「原辰徳が」）

「隠す言葉」は異体字を区別します。「高橋」と入れても「髙橋」は隠れないので、両方入れてください。

逆に、名前を残さないよう、次のものも隠れることがあります。

- 「患者さん」「利用者様」のような言葉
- 名字と同じ字で始まる地名や社名（「上野駅」「山口県」など）
- 「金曜日」だけの行、「専門家」の「専門」

## 画面の文字

- 隠せるのは、読み取れた文字だけです。次のものは残ることがあります：
  - 小さい文字、画像や動画の中の文字、一瞬だけ映った文字
  - 2 行以上下に続く住所
  - 3 行以上にわたるメールアドレス・URL の続き
  - 日本語のドメインの URL
  - とても速いスクロール中の文字
- 逆に、住所の下の行や、行末と次の行頭の数字（日付・金額など）が多めに隠れることがあります
- 画面をカメラで撮った動画では、ブレ・反射・指で読み取れない間に文字が見えることがあります
- 画面を斜めに撮った動画では、モザイクは傾いた行を囲む四角になるので、まわりの文字も一緒に隠れることがあります
- 「読み取れた文字をすべて隠す」は、動画に入れた字幕や、服・看板の文字も隠します。字幕を入れる前の動画に使ってください

## 対応している動画形式

- 開けるもの：MOV・MP4・M4V など、macOS で再生できる動画（H.264・HEVC・ProRes・AV1 など）
- MXF（Sony FX6/FX3 など）：ffmpeg（`brew install ffmpeg`）が入っていれば、自動で読める形にして開きます
- 開けないもの：MKV・WebM・WMV・FLV（MP4 や MOV に変換してから使ってください）
- 書き出しは元の動画と同じ形式（H.264・HEVC・ProRes など）で、音声はそのままコピーします。元のファイルは変更しません

## 処理と保存の場所

- 顔の検出、人のまとめ、画面の文字の読み取り、モザイク、書き出しは、macOS に最初から入っている機能（Vision・Core Image・AVFoundation）だけで、この Mac の中で行います。アプリにも CLI にも通信の処理はありません
- 登録した顔写真と設定は、この Mac の中に保存するだけです。顔写真の保存場所は `~/Library/Application Support/WipeMosaic/faces/`、スタンプの画像は `~/Library/Application Support/WipeMosaic/stickers/` です（`WipeMosaic` は開発中の名前です）
